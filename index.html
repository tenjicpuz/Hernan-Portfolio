How I approach a project

A practical workflow helps me turn an idea into something that can be tested, understood, and improved.

01 / UNDERSTAND

Define the problem

Clarify the goal, intended users, key requirements, and what a useful result should accomplish.

02 / BUILD

Develop in steps

Break the work into manageable parts, choose suitable tools, and implement the core experience.

03 / REFINE

Test and improve

Check the result, investigate issues, improve clarity, and document what was learned.
